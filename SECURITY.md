# Security

Orbit runs coding agents on pull request code on your computer, so security problems matter. The [README](README.md#safety-at-a-glance) and the [user guide](docs/user-guide.md) describe what Orbit protects against and where its limits are.

## Reporting a problem

Please don't report security problems in a public issue. Instead, use **Report a vulnerability** on the repository's [Security tab](https://github.com/analogproblems/orbit/security). Only the maintainer can read the report.

Include what you found, how to reproduce it, and what someone could do with it. You'll get a reply as soon as the maintainer can look at it.

## Supported versions

Only the latest version on the `master` branch gets fixes.
